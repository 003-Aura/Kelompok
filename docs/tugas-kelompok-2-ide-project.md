# Tugas Kelompok 2 — Judul / Ide Project Akhir

## 1. Judul Final

**Kelompok-XX-E-Library**

## 2. Cerita yang Dipilih dan Alasan

**Cerita yang dipilih:** E-Library

E-Library dipilih karena merupakan sistem informasi perpustakaan berbasis web yang membantu proses pengelolaan data buku, user, peminjaman, dan pengembalian buku. Project ini memiliki pengguna yang jelas, yaitu Admin, Petugas, dan User, serta dapat dikembangkan sesuai kebutuhan sistem perpustakaan.

## 3. Masalah, Pengguna, dan Fitur MVP

* **Masalah:** Pengelolaan data buku serta proses peminjaman dan pengembalian perlu dilakukan secara lebih terkomputerisasi dan terstruktur.
* **Pengguna:** Admin, Petugas, dan User (Mahasiswa).
* **Fitur MVP:** Login menggunakan NIM, melihat dan mencari buku, melihat detail buku, melakukan peminjaman dan pengembalian, serta melihat riwayat peminjaman.

## 4. Peran Pengguna

| **No** | **Peran**        | **Fungsi**                                                                                                                |
| -----: | :--------------- | :------------------------------------------------------------------------------------------------------------------------ |
|      1 | Admin            | Mengelola data buku, mengelola data user, dan melihat dashboard sistem.                                                   |
|      2 | Petugas          | Mengelola proses peminjaman, pengembalian, dan data peminjaman.                                                           |
|      3 | User (Mahasiswa) | Login menggunakan NIM, melihat dan mencari buku, melakukan peminjaman dan pengembalian, serta melihat riwayat peminjaman. |

## 5. Arsitektur Sistem

```text
Svelte → REST → Express → Prisma → Database
Flutter → REST
```

Web dan mobile menggunakan REST API yang sama untuk terhubung dengan backend dan database.
